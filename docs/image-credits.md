## Not photographs

- **Concept project screenshots** (`public/work/ndlovu-*.webp`, `thandeka-*.webp`, `fazila-*.webp`): screenshots of our own concept sites, which are not commissioned client work. The Ndlovu Electrical screenshot is used on the homepage and the examples page. The Thandeka and Fazila tiles now use drawn mock-ups in the site palette, so their screenshots are unused for now.
- **Icons** (`src/components/Icon.astro`): simple line icons drawn for this site on a 24 px grid. No third-party icon set or icon font is used, so there is no outside icon licence to credit. The drawings are covered by the repository licence.
- **Logo** (`public/brand/`): original artwork made for Straat Studio. The lettering is outlined from Inter (SIL Open Font License 1.1), which is also the site font.
- **Font**: Inter, SIL Open Font License 1.1, self-hosted in `public/fonts/inter.woff2`.
